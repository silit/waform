Install

Two ways to install

Fastest: the Webflow app. Click Install, allow the site, enter your number, done. The snippet route below works on any plan and any form.

Paste the snippet

Site settings, Custom code, Footer code. Save and publish. The script loads after the page, so it never slows the page down.

Give every form a number

The snippet sets one number for the whole site. A form can use another number through a custom attribute on the form element: data-wa-number with the number as the value. Opt a form out with data-wa set to off.

Send a test

Submit the form on the published site. Desktop opens a WhatsApp tab and shows a button in the success message; phones jump to WhatsApp after Webflow confirms the submission.

Reference

Every setting, three ways to set it

Priority from low to high: window.WAFormConfig in the snippet, then attributes on the script tag, then attributes on the form element. Field names in placeholders match the Webflow field name or its label, ignoring case, spaces and dashes.

data-wa="off"Leaves this form alone.
  • Checkboxes send "Yes" or their value; checkbox groups with the same name are joined with commas; selects send the option text.
  • On iPhone, Safari can show the wa.me page with a "Continue to chat" button first, because the jump happens after Webflow confirms the submission. For an instant jump set data-wa-submit="false".
  • Forms outside Webflow's form block work too. Use data-wa-submit="false" or data-wa-mode="button" for those.
  • From code, listen for waform:submit on the form. The event carries the message and the link, and preventDefault() cancels the jump. WAForm.linkFor(form) returns the link for your own buttons.
  • Nothing is stored or sent anywhere except to WhatsApp and to Webflow. No cookies, no analytics.
